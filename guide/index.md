# JARVIS AI — Guide

This guide explains how JARVIS works, one layer at a time. The [README](../README.md) is the place to
start; this is where the details live.

> Written from the code in November 2026 (v3.8.1).

## How it fits together

```
          you
           │
 ┌─────────▼──────────────────────────────────────────────────────┐
 │ 1. Interfaces     CLI · chat · agent chat · web UI · voice     │
 ├────────────────────────────────────────────────────────────────┤
 │ 2. Program        startup, services, events, modules           │
 ├────────────────────────────────────────────────────────────────┤
 │ 3. Agents         pipelines, agent loop, context management    │
 ├───────────────────────────────┬────────────────────────────────┤
 │ 4. Tools                      │ 5. Knowledge & memory          │
 │ files, search, shell, web,    │ project knowledge,             │
 │ notify, MCP, your own         │ long-term memory               │
 ├───────────────────────────────┴────────────────────────────────┤
 │ 6. Models         Ollama · GGUF · HF · OpenAI · Gemini · JARVIS │
 └───────────────────────────────┬────────────────────────────────┘
                                 │ (optional, over HTTP)
 ┌───────────────────────────────▼────────────────────────────────┐
 │ 7. Server         Brain Server · relay · API · auth · web UI   │
 └────────────────────────────────────────────────────────────────┘

 Around all of it:
   8. Configuration — config.json, the AI folder, templates and prompts
   9. Installation  — build scripts, optional engines, Windows executable
  10. Development   — tests, releases, changelog
```

A typical agent run: you type a message (1) → the program loads the config, the model and the
modules (2) → the agent pipeline sends your message to the model with the tool list and relevant
project knowledge (3, 5) → the model answers with a tool call → the tool runs, asking you first if
it's risky (4) → the result goes back to the model → repeat until it answers you.
