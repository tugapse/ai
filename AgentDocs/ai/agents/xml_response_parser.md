## 1. Overview & Purpose
| Component | Source File |
| :--- | :--- |
| **ResponseParser** | [src/ai/agents/xml_response_parser.py](/AgentDocs/ai/agents/xml_response_parser.md) |

The `ResponseParser` class is responsible for transforming raw string outputs from AI agents into structured, actionable data. It specifically targets responses wrapped in `<response>` XML tags, which contain nested structures such as internal thought processes, manifests, tool execution parameters, and user-facing messages.

This component acts as a critical parsing layer within the agent architecture. It ensures that the unstructured text generated by Large Language Models (LLMs) is correctly interpreted as structured commands or data, allowing the system to execute tool calls and manage agent state effectively.

## 2. Public API & Interfaces

| Entity | Type | Description |
| :--- | :--- | :--- |
| `ResponseParser(parameter_mode="xml")` | Class | Initializes the parser. `parameter_mode` determines if `tool_parameters` are parsed as XML child tags or a JSON string. |
| `parse(raw_string: str) -> Dict[str, Any]` | Method | The primary entry point. Takes a raw string, extracts the `<response>` block, and returns a dictionary containing `status`, `thought`, `notes`, `manifest`, `action`, and `response_to_user`. |

## 3. Implementation Details & Side Effects
- **Core Logic:** 
    - The parser first attempts to locate `<response>` boundaries and parse the content using `xml.etree.ElementTree`.
    - **Salvage Mechanism:** If initial XML parsing fails (often due to LLM-generated special characters like `<` or `>` inside text blocks), the `_sanitize_block` method uses regular expressions to find specific tags (`thought`, `notes`, `response_to_user`) and escapes their content to make the XML valid for a second parsing attempt.
    - **Parameter Extraction:** Depending on `parameter_mode`, it either iterates through XML child elements to build a dictionary or attempts to `json.loads()` the text content of the element.
- **Side Effects:** 
    - Calls `func.log` via [ai.functions](/AgentDocs/ai/functions.md) when a salvage operation is triggered due to a parsing failure.
- **Error Handling:** 
    - Returns a dictionary with `"status": "FAILED"` and an error message if boundaries are missing, if the salvage operation fails, or if a system exception occurs.
    - If JSON parsing is selected for parameters and fails, it returns an error dictionary within the `tool_parameters` field rather than crashing the entire parse.
