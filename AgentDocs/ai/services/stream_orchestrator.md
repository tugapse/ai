## 1. Overview & Purpose
| Component | Source File |
| :--- | :--- |
| **StreamOrchestrator** | [src/ai/services/stream_orchestrator.py](/AgentDocs/ai/services/stream_orchestrator.md) |

The `StreamOrchestrator` is responsible for the real-time processing and routing of token streams generated by AI models. It acts as a central coordination layer that sanitizes incoming raw data, manages the accumulation of text for conversation history, and directs content to the appropriate output channels, such as the terminal UI or the voice synthesis system.

This component sits within the service layer of the application architecture, bridging the gap between raw LLM outputs and the user-facing presentation modules. It ensures that tool calls are handled silently (to maintain valid conversation history without cluttering the UI) while ensuring that standard text responses are both printed to the console and fed into the `SpeechBridge` for auditory feedback.

## 2. Public API & Interfaces

| Entity | Type | Description |
| :--- | :--- | :--- |
| `StreamResult` | Dataclass | A container for the results of a completed stream, containing `accumulated_text` (str), `interrupted` (bool), and `tool_calls` (List[Any]). |
| `StreamOrchestrator` | Class | The primary orchestrator for managing token stream lifecycles. |
| `StreamOrchestrator.run(stream_generator)` | Method | Consumes an iterable `stream_generator` yielding tokens. It returns a `StreamResult` and handles the full orchestration logic, including sanitization and routing. |

## 3. Implementation Details & Side Effects
- **Core Logic:** The orchestrator iterates through a generator. It performs three main tasks per token: 
    1. **Sanitization:** Uses `unicodedata` to normalize tokens and regex to strip non-printable characters.
    2. **Routing:** Uses a `handler_manager` to determine if a token is a UI element or a tool call.
    3. **Accumulation:** Maintains a running string of all content (including tool calls) to ensure the LLM's context window remains consistent and prevents errors related to empty histories.
- **Side Effects:** 
    - **Console I/O:** Directly prints formatted text to the standard output via the `OutputPrinter`.
    - **Voice I/O:** Feeds content to the `SpeechBridge` for real-time audio generation.
    - **Callback Execution:** Executes the `on_tool_call` callback if provided.
- **Error Handling:** 
    - Captures `KeyboardInterrupt` to gracefully abort the `SpeechBridge` and return a partial `StreamResult` marked as `interrupted`.
    - Re-raises generic `Exception` after attempting to flush the `SpeechBridge`.
