## 1. Overview & Purpose
| Component | Source File |
| :--- | :--- |
| **StreamOrchestrator** | [src/ai/services/stream_orchestrator.py](/src/ai/services/stream_orchestrator.py) |

The `StreamOrchestrator` is responsible for managing the real-time lifecycle of a token stream generated by an AI model. It acts as a central coordination point that ingests raw tokens, sanitizes them, and routes them to the appropriate subsystems for display, voice synthesis, or tool execution.

This component sits within the service layer of the application architecture, bridging the gap between the raw LLM output and the user-facing interfaces. It ensures that text is accumulated correctly for conversation history (preventing API errors), manages the distinction between visible UI content and silent tool calls, and interfaces with the [SpeechBridge](/ai/modules/voice/speech_bridge.md) to provide auditory feedback.

## 2. Public API & Interfaces

| Entity | Type | Description |
| :--- | :--- | :--- |
| `StreamResult` | Dataclass | A container for the results of a streaming session, containing `accumulated_text` (str), `interrupted` (bool), and `tool_calls` (List[Any]). |
| `StreamOrchestrator` | Class | The primary orchestrator for processing token streams. |
| `StreamOrchestrator.run(stream_generator)` | Method | Consumes an iterable of raw tokens, processes them through sanitization and handlers, and returns a `StreamResult`. |

## 3. Implementation Details & Side Effects
- **Core Logic:** The orchestrator iterates through a generator of tokens. It performs three main tasks for each token: 
    1. **Sanitization:** Uses `unicodedata` to normalize strings to NFKC and regex to strip non-printable characters.
    2. **Routing:** Uses a `handler_manager` to determine if a token is intended for the UI or represents a tool call.
    3. **Accumulation:** Maintains a running string of all content (including tool calls) to ensure the LLM's conversation history remains consistent.
- **Side Effects:** 
    - **Console I/O:** Directly prints processed tokens to the terminal via the `OutputPrinter`.
    - **Voice I/O:** Feeds content to the `SpeechBridge` for real-time text-to-speech.
    - **Callback Execution:** Triggers the `on_tool_call` callback when tool logic is detected.
- **Error Handling:** 
    - Catches `KeyboardInterrupt` to gracefully abort the `SpeechBridge` and return a partial `StreamResult` marked as `interrupted`.
    - Catches general `Exception` to ensure the `SpeechBridge` is flushed before re-raising the error.
